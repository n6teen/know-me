## โจทย์

นายจ้างและแรงงานต้องการแพลตฟอร์มที่เชื่อถือได้ในการเชื่อมต่อ จัดการสัญญา และ workflow การดำเนินงานอย่างมีประสิทธิภาพ โซลูชันที่มีอยู่ยังกระจัดกระจายและไม่ครอบคลุมทุก lifecycle ของการจัดการแรงงาน

## วิธีคิดและวิธีทำ

โน้ตมีส่วนร่วมอย่างมากทั้งในการออกแบบและพัฒนา ทำงานตลอดทั้ง lifecycle ของ product เริ่มจากการวาง user flow และออกแบบ UX/UI แล้วจึง implement ฟีเจอร์ frontend และ backend ทำงานใกล้ชิดกับทีม product เพื่อแปลง requirement ธุรกิจเป็นโซลูชันทางเทคนิคที่ตอบโจทย์ทั้งนายจ้าง แรงงาน และทีมปฏิบัติการ

## ผลลัพธ์

แพลตฟอร์มเชื่อมต่อนายจ้างกับแรงงานได้สำเร็จ พร้อมจัดการความซับซ้อนของ operational workflow การทำงานข้าม stack ช่วยให้มั่นใจได้ว่า user experience และระบบเบื้องหลังสอดคล้องกัน
